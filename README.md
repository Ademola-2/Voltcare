# VoltCare ⚡

**Powering Your World, Intelligently.**

VoltCare is a global-first electrical engineering and energy planning platform. The long-term vision combines practical electrical calculators, solar planning estimates, learning resources, and connections to qualified electrical and solar service professionals.

## Current status

The first responsive homepage is in progress. Tool cards currently introduce planned features; they do not yet perform calculations.

## Planned tools

- Electrical calculator (voltage, current, resistance, and power)
- Electrical load estimator
- Energy consumption calculator (Wh and kWh)
- Preliminary solar and battery planner
- Electrical engineering learning centre
- Later: service listings and quotation enquiries

## Technology

- React
- JavaScript
- Vite
- Regular CSS
- Lucide icons

## Run locally

Install a current Node.js LTS release, then run:

```bash
npm install
npm run dev
```

## Engineering note

VoltCare's calculators are intended to support learning and preliminary estimates. They must clearly state assumptions and limitations. Real installations must be designed and checked against applicable local standards by qualified professionals.

## Vision

Make electrical engineering and energy planning easier to understand for people around the world.
